# money-glitch-free

Tamper Monkey: [install](https://raw.githubusercontent.com/GameOneDev/money-glitch-free/main/kahoot-ai-claude.user.js)

Works on Kahoot (kahoot.it), Mentimeter quizzes (menti.com) and AhaSlides quizzes (audience.ahaslides.com). The API key is saved per site, so paste it once on each.

On AhaSlides it answers multiple choice (including questions with several right answers), short answer, correct order, match pairs and categorise slides, live or self-paced. Slides whose question or answers are only pictures are skipped.
